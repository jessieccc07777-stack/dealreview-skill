# 条款卡库 · 公司视角（被投资方 / 创始团队）

> 本文件是 DealReview 的**审查主依据**。每张卡片按六段展开：
> 【条款含义（投资人目的）】→【对公司/创始团队的不利点】→【公司方谈判要点】→【典型可接受的写法建议】→【可接受底线（促成交易尺度）】→【来源（综合公开实务来源/判例）】。
>
> 视角原则：PRIMARY 受益人 = 公司 + 创始团队；投资人的"市场惯例"是谈判起点而非目标；凡涉创始人个人风险（连带/质押/担保/配偶共债）一律给出限缩路径。

---

## 1. 回购权（Redemption Right）

**【条款含义（投资人目的）】** 约定情形（未合格上市、重大违约、严重违法等）出现时，按"本金 + 约定收益（常见 8%–15%）"买回股权，是投资人最主要的保底退出机制。九民纪要后公司与创始人对赌均有效，但公司回购受资本维持限制，实务常要求创始人与公司连带。

**【对公司/创始团队的不利点】** 公司是回购义务人的须走定向减资（新《公司法》第 224 条以同比为原则，定向减资须全体股东一致同意），履行极不确定；创始人连带 → 个人无限责任，击穿有限责任；加速到期条款（任一轮触发即本轮全部触发）→ 被动背前轮风险；复利叠加、后轮优先 → 现金流与个人财产被层层抽血。

**【公司方谈判要点】** 限定义务人（优先仅创始人、公司不回购；若含公司则以减资为前置且非第一顺位）；责任边界（力推"以所持股权为限"，拒绝"以全部个人财产为限""以股权价值为限"）；剔除个人连带；设回购上限（本金 + 单利 8%，免复利）；日落条款（IPO 申报/交割后 7 年消灭，或触发起 X 月不行使即失权）。

**【典型可接受的写法建议】** "若发生回购触发事件，创始人（甲方）有义务以届时所持目标公司股权（含其对应财产权益）为限向投资人支付回购价款，金额为投资本金加按单利 8% 计算之收益；公司不承担赔偿责任，亦不就创始人义务提供任何担保。任何回购请求权自触发事由发生之日起 24 个月内未书面行使的，视为永久放弃。"

**【可接受底线（促成交易尺度）】** 可接受：创始人以所持股权为限的单利 8% 回购 + 180 日行权期限 + IPO 申报日落。不可接受（须清除/改造）：创始人个人无限连带、以全部个人财产为限、复利、加速到期、公司刚性兑付式回购。交换条件：接受投资人 1 席董事 + IPO 前不优先分红，以换取删除个人连带。

**【来源】** 综合公开实务文章与司法判例（九民纪要；锦天城、法律桥、大成、兰台等公开 SHA/对赌实务；小马奔腾案 (2021)京民终18号 等）。

## 2. 回购权深化（触发 / 减资 / 抗辩 / 违约金 / 国资）

**【条款含义（投资人目的）】** 细化回购：触发条件（未达合格上市/重大违约/严重违法/重大损失 + 加速到期）；公司回购须经定向减资；主张长期有效、随时主张；高收益 + 高违约金。

**【对公司/创始团队的不利点（含有利抗辩点）】**
- 触发："未达合格上市"遇 A 股关窗 → 被动违约；"重大违约"宽泛 → 任何偏差即触发；加速到期背前轮风险。
- 减资：定向减资须全体股东一致同意——**这是公司方最重要的法定制衡点**：其他股东不配合即决议停滞，法院难支持强制减资，公司可合法阻却回购履行（但须审慎站位）。
- 抗辩：回购权性质更接近形成权，适用除斥期间；"未约定期限的合理期间原则上不超 6 个月"（法答网第九批 2024-08），投资人迟延主张时公司方有抗辩空间。
- 违约金：法院秉持补偿性原则，过高依《民法典》第 585 条调减；计息过高可调至 4 倍 LPR。
- 国资：若领投含国资，监管禁止"明股实债"式回购（2025-02-18《企业国有资产交易操作规则》第 30 条；中基协 2025-12-01 条款提示）——对公司方是合规闸门，善用可阻止刚性兑付主张成立。

**【公司方谈判要点】** 删/限加速到期；上市以"受理/批准"为准、排除"准备/启动"；增 Regulatory Carve-out（监管关窗不违约）；公司回购以定向减资（全体股东一致）为前置，公司仅负诚信推动义务、不就未通过担付款责；明确约定行权期限（如触发起 180 日）把"6 个月争议"转为对己方确定短期限；违约金封顶（收益 + 违约金择一，收益上限单利 8%）；国资通道改用"估值调整/业绩补偿"框架并走评估进场。

**【典型可接受的写法建议】** "回购权自触发事由发生之日起 180 日内未书面行使的，视为永久放弃。公司回购以完成定向减资（须股东会全体股东一致通过）为前置，公司仅负有推动减资的诚信义务，不就减资未获通过承担任何付款责任。固定收益与违约金择一适用，收益上限为投资本金按单利 8% 计算。"

**【可接受底线】** 可接受：180 日短期限 + 减资前置制衡 + 单利 8% + 违约金择一。不可接受：无期限回购 + 公司无条件付款承诺 + 收益违约金叠加 + 国资明股实债表述。交换条件：接受较短 IPO 时间窗（如 5 年）以换取删除加速到期。

**【来源】** 综合公开实务与判例（法答网第九批；沪01民终12277号；(2023)粤01民终33037号 20%→15.4%；(2021)京民终495号；锦天城、兰台、大成、国浩公开回购实务）。

## 3. 优先清算权（Liquidation Preference）

**【条款含义（投资人目的）】** 清算或"视同清算"（整体股权出售、全部资产实质出售、控制权变动）时，投资人先于其他股东收回"本金 + 约定收益"，余下按持股分配。强势者要求"参与分配"（double-dip）。

**【对公司/创始团队的不利点】** 法定清算时公司资产多已被债权人耗尽，优先权实际落空；真正有实益的是"视同清算"（并购），但此时创始人可能分文未得而投资人已回本；完全参与 + 无上限 → 并购退出创始人几乎拿不到剩余；"视同清算"定义过宽 → 正常经营处置资产也被截留。

**【公司方谈判要点】** 争取非参与优先清算或设回报上限（本金 + 1 倍收益封顶，或达 X 倍转普通股同权）；收窄"视同清算"定义（仅限导致控制权变更的整体出售，排除日常资产处置/普通融资/子公司股权变动）；顺位对等（避免后轮倒挂，并购达门槛后全体股东同权）；与拖售/回购联动统筹。

**【典型可接受的写法建议】** "发生视同清算事件且交易对价超过【投后估值 3 倍】的，投资人优先清算额以投资本金加单利 10% 收益为上限，超过上限部分按各股东持股比例分配；本优先清算权不适用于任何单一资产账面净值低于公司总资产 20% 的资产处置。"

**【可接受底线】** 可接受：非参与 + 回报上限（本金 + 单利 10%）+ 高门槛后同权。不可接受：完全参与无上限 + "视同清算"定义含日常资产处置。交换条件：接受优先清算本身（市场惯例）以换取非参与 + 上限。→ 此条通常进「建议放行清单（🟢）」的"已限缩版"。

**【来源】** 综合公开 SHA/特殊股东权利实务（锦天城、恒都、德和衡等公开文章）。

## 4. 反稀释（Anti-Dilution）

**【条款含义（投资人目的）】** 后续轮估值低于本轮（流血融资）时调低前轮单价、补偿股数。两模式：完全棘轮（前轮单价直降至新单价，对创始人最狠）、加权平均（广义/狭义，更友好）。

**【对公司/创始团队的不利点】** 完全棘轮 → 下行融资时创始人被无偿转出大量老股；补偿以创始人无偿/名义对价转老股执行 → 触发自然人所得税，税负承担易争议；与优先认购权叠加 → 后续融资空间双向挤压。

**【公司方谈判要点】** 只接受加权平均、拒绝完全棘轮；明确豁免清单（员工激励平台低价增资、战略合作/并购发行、可转债转股、拆股）；税负由公司承担或投资人自担；价值时点锁定为投后估值而非触发时点。

**【典型可接受的写法建议】** "反稀释调整仅采用【广义加权平均】方式。下列发行不触发本条款：经董事会（含投资人董事）批准的员工股权激励计划项下的发行、为收购或战略合作而发行的股份、可转债或认股权证之转股/行权。因本条款产生的任何税务成本由公司承担。"

**【可接受底线】** 可接受：广义加权平均 + 员工激励豁免 + 公司担税。不可接受（🔴红线）：完全棘轮无下限。交换条件：接受加权平均以换取删除完全棘轮与税负转嫁。

**【来源】** 综合公开 SHA/新公司法实务（锦天城、恒都、基小律公开文章）。

## 5. 对赌与估值调整（Valuation Adjustment / VAM）

**【条款含义（投资人目的）】** 以业绩/事件为锚，未达标则触发现金或股权补偿，弥补高估值风险。常与回购"二选一"。

**【对公司/创始团队的不利点】** 由公司对赌现金补偿 → 涉抽逃出资/资本公积返还争议（九民纪要第 35 条审查资本维持），司法分歧大；补偿无上限 → 现金流枯竭；指标模糊 → 争议被动。

**【公司方谈判要点】** 早期公司非必备，尽量不签；中后期用量化锚且设补偿上限；避免公司现金补偿，改创始人以股权为限补偿或仅股权调整；指标必须可计算（方法/审计/考核期）；与回购择一不叠加。

**【典型可接受的写法建议】** "若【202X】年度经审计净利润低于承诺值的 80%，创始人（以所持股权为限）向投资人补偿差额对应的股权，补偿后投资人持股比例增加不超过【X】%；本补偿义务与公司无关，且不与回购权同时主张。"

**【可接受底线】** 可接受：创始人以股权为限的股权补偿 + 上限 + 与回购择一。不可接受：公司现金补偿无上限 + 与回购叠加。交换条件：接受股权补偿以换取删除公司现金补偿。

**【来源】** 综合公开对赌实务（锦天城、兰台、大成公开文章及九民纪要）。

## 6. 拖售权 / 领售权（Drag-Along）

**【条款含义（投资人目的）】** 满足前提时可强制其他股东（含创始人）一并出售股权，实现整体收购退出。

**【对公司/创始团队的不利点】** 直接致创始人失去企业，价格/对象可能不利；"小拖大"：少数股权小投资人亦可启动；与优先清算"视同清算"联动 → 同一出售事件收益被双重截留。

**【公司方谈判要点】** 时间门槛（交割后 N 年内不得行使）；估值门槛（必备，总对价须达特定金额，低于不得拖售）；表决门槛（多轮时须一定比例享有拖售权股东同意）；除外情形（创始人保留按比例参与同售；排除卖给竞争对手、排除致创始人个人连带的出售结构）。

**【典型可接受的写法建议】** "任一投资人行使拖售权，须同时满足：(a) 自交割日起已满 5 年；(b) 交易总对价不低于【投资本金 3 倍】；(c) 代表过半数享有拖售权股份的股东同意。创始人有权按其持股比例参与本次出售，且本出售不得导致创始人承担任何个人连带付款义务。"

**【可接受底线】** 可接受：5 年时间门槛 + 3 倍估值门槛 + 过半数表决 + 创始人同售 + 排除个人连带。不可接受（🔴）：无门槛小拖大 + 致创始人个人连带。交换条件：接受拖售本身（并购退出需要）以换取三门槛 + 排除连带。

**【来源】** 综合公开 SHA/特殊股东权利实务（锦天城、恒都、德和衡等）。

## 7. 随售权 / 共同出售权（Tag-Along / Co-Sale）

**【条款含义（投资人目的）】** 创始人（大股东）对外转让时，投资人有权按比例"搭车"同售，防创始人先于投资人套现。

**【对公司/创始团队的不利点】** 创始人正常转股（税务筹划/家族传承/少量改善个人经济）被绑定；高估值时随售比例悬殊 → 实际套现落空；与优先购买权、拖售权顺位不清 → 冲突。

**【公司方谈判要点】** 自由转让额度例外（不超持股 X%，3%–10%，不适用随售；税务筹划/家族传承/转员工平台亦例外）；先决条件（以投资人已书面豁免转股限制为启动前提）；计算明确（标准共售公式）。

**【典型可接受的写法建议】** "投资人共售比例 = 投资人持股 ÷（含投资人在内拟共售全体股东持股之和 + 转让方创始人持股）× 创始人拟售股数。创始人每 12 个月内转让不超过其持股 5% 的，不适用本条；创始人向配偶、子女或员工持股平台转让的，亦不适用。"

**【可接受底线】** 可接受：5% 年度自由额度 + 配偶/子女/员工平台例外。不可接受：零自由额度 + 高估值全比例随售。交换条件：接受随售本身以换取自由额度例外。→ 限缩版通常可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA 实务（锦天城、恒都等）。

## 8. 优先购买权（ROFR）与优先认购权（PRS）

**【条款含义（投资人目的）】** ROFR：创始人转股时投资人优先于第三方购买；PRS：公司增资时投资人优先认购，维持比例防稀释。

**【对公司/创始团队的不利点】** ROFR 阻碍创始人向员工平台低价激励、税务平移；PRS 在股份公司阶段是否保留不明确 → 后续融资每次被截胡；善用《公司法》30 日默示同意规则（投资人沉默即丧失权利对公司有利）。

**【公司方谈判要点】** ROFR 例外（经批准的员工平台激励、税务筹划平移、创始人之间转让、履行反稀释/估值调整必须的转让）；PRS 限缩（仅按增资前股比、增资后持股不高于某比例、仅在其他方未充分行权时超额认购；员工平台豁免）；行权程序友好化（收到通知后 X 日内书面行权，逾期视为放弃）。

**【典型可接受的写法建议】** "投资人优先认购权不适用于：(a) 经董事会批准之员工股权激励计划；(b) 为收购/战略合作发行之股份；(c) 可转债转股。投资人未于收到增资通知后 15 个工作日内书面主张优先认购的，视为放弃。"

**【可接受底线】** 可接受：员工平台/战略合作豁免 + 15 日逾期视为放弃。不可接受：无例外全覆盖 + 无行权期限（永久截胡）。交换条件：接受 PRS 本身以换取例外清单。→ 含例外的版本可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA/新公司法实务（锦天城、恒都、基小律等）。

## 9. 无歧视待遇 / 最惠国（MFN / Most-Favored-Nation）

**【条款含义（投资人目的）】** 投资人自动享有公司后续给予任何股东的更优权利，抹平信息不对称。

**【对公司/创始团队的不利点】** 后轮让步被前轮"搭车"自动享有 → 谈判空间锁死；举证难（抽屉协议下难查证，但投资人可用书证提出命令倒逼披露）。

**【公司方谈判要点】** 界定范围（仅同轮同批次或明确列举权利类型，排除后轮因特殊贡献获得的定向优惠）；含创始人提供条件（创始人自行向第三方提供的条件不触发）；设终止时点（合格 IPO 申报前终止）。

**【典型可接受的写法建议】** "最惠国条款仅适用于本轮投资人，且不适用于公司基于后轮投资人提供战略资源、业务合作或业绩承诺而给予的任何特别权利；创始人以个人身份向第三方提供的优惠不在本条款范围内。"

**【可接受底线】** 可接受：范围限定 + 创始人个人安排除外 + IPO 前终止。不可接受：无范围无终止、覆盖一切后轮优惠。交换条件：接受 MFN（投资人合理诉求）以换取范围限定。

**【来源】** 综合公开 SHA/VC 法记公开系列。

## 10. 限售权 / 创始人持股限制（Lock-Up / Founder Restriction）

**【条款含义（投资人目的）】** 上市前创始人不得转让股权，保证团队稳定；少数情况允许少量出售权改善个人经济。

**【对公司/创始团队的不利点】** 上市前全锁 → 无法改善个人现金流/家族税务筹划；自由额度未列随售例外 → 设计落空；限制性股权解锁过严（3–5 年阶梯、离职即回购未解锁）→ 被动离职大额失血。

**【公司方谈判要点】** 保留自由额度（3%–10%，且不适用随售/优先购买）；解锁机制宽松化（缩短兑现期 2–3 年、区分主动/过错/被迫离职价格、仅限经济权益不限制表决权）；例外列举（税务筹划、家族传承、转员工平台、履行反稀释/估值调整必须转让）。

**【典型可接受的写法建议】** "上市前创始人原则上不得转让股权，但下列情形除外且不适用优先购买/共售权：(a) 每 12 个月转让不超过其持股 5%；(b) 向配偶、子女或家族信托转让；(c) 经董事会批准之员工平台激励平移。限制性股权仅限制经济权益，不影响表决权。"

**【可接受底线】** 可接受：5% 年度自由额度 + 家族/员工平台例外 + 仅限经济权益。不可接受：零额度全锁 + 离职即回购全部未解锁（含表决权）。交换条件：接受限售本身（投资人合理诉求）以换取自由额度与例外。→ 限缩版可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA 实务（锦天城、恒都等）。

## 11. 一票否决权（Veto / Protective Provisions）

**【条款含义（投资人目的）】** 股东会/董事会层面对重大事项设否决权，保护股权结构与治理。常见 11 项左右（修章程、增减资、合并重组、变更主营、处分主要资产、对外担保、分红、聘解高管、上市方案等）。

**【对公司/创始团队的不利点】** 清单过长 → 日常经营被掣肘；投资人董事缺席即决议无效 → 公司卡死；否决权与"修改投资人权利"挂钩 → 后续融资/重组极难调整。

**【公司方谈判要点】** 聚焦清单（仅留真正重大影响股权结构与控制权的事项，删"调整董事会构成""普通对外投资"等日常项）；设反僵局机制（董事缺席可延期一次、仍缺席视为同意/其余董事合法开会）；日落/比例稀释失效（持股低于 5% 自动终止，或合格 IPO 后消灭）。

**【典型可接受的写法建议】** "投资人董事就下列事项享一票否决权：【修改章程中投资人权利条款、公司合并/分立/解散、单笔超过净资产 10% 的资产处置、对外提供超过【X】万元担保】。投资人董事经两次书面通知仍未出席的，视为放弃否决、其余董事可合法决议。投资人持股低于 5% 时本条自动终止。"

**【可接受底线】** 可接受：4–5 项核心否决 + 反僵局 + 5% 日落。不可接受：长清单全覆盖 + 无反僵局 + 无日落。交换条件：接受有限否决（治理保护）以换取清单缩短与日落。→ 限缩版可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA 实务（锦天城、国创、德和衡等）。

## 12. 信息权与检查权（Information & Inspection Rights）

**【条款含义（投资人目的）】** 定期获取财报、重大事项通报，并查账（含全资子公司、会计凭证），弥补信息不对称。

**【对公司/创始团队的不利点】** 新《公司法》已将知情权扩至全资子公司 + 会计凭证；协议再放大 → 商业机密/客户名单暴露；检查权频率/范围无约束 → 干扰经营。

**【公司方谈判要点】** 频率与范围限定（财务按季/半年；查账须提前书面通知、限定范围、公司可要求在场）；保密对价（投资人签署保密承诺，不得用于投资竞争对手）；以新《公司法》知情权为上限，不额外扩张。

**【典型可接受的写法建议】** "公司应于每会计年度结束后 90 日内提供经审计合并财报，季度结束后 30 日内提供管理报表。投资人查账须提前 10 个工作日书面通知、在公司场所进行并签署保密协议，查账范围限于会计账簿及凭证，不包括未公开之客户名单与算法代码。"

**【可接受底线】** 可接受：按季/半年财报 + 提前通知查账 + 保密承诺 + 上限为法定知情权。不可接受：随时无限制查账 + 扩张至未公开敏感数据。交换条件：接受信息权（合理）以换取范围限定。→ 限缩版可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA/新公司法实务（锦天城、法律桥、基小律等）。

## 13. 董事委派与观察员（Board Nomination & Observer）

**【条款含义（投资人目的）】** 领投方委派 1 名董事参与治理；无席位轮次派观察员（无表决权但列席）。

**【对公司/创始团队的不利点】** 投资人董事缺席致决议无效；新《公司法》下董事责任加重（核查出资、忠实勤勉、清算义务人=董事）→ 可能要求公司免除风险/补偿，间接增成本；子公司董事会提名权外溢。

**【公司方谈判要点】** 控盘底线（创始人保 >50% 席位，投资人仅 1 席或观察员）；董责险 + 书面留痕（为全体董事投保，投资人董事履职书面留痕）；观察员无表决权、不计入法定人数；缺席处理（延期机制）。

**【典型可接受的写法建议】** "董事会由【N】名董事组成，创始人委派【N-1】名，领投方委派 1 名，其余轮次派观察员（无表决权）。公司应为全体董事投保董责险。投资人董事经延期一次仍缺席的，其余董事可合法召开会议。"

**【可接受底线】** 可接受：创始人控 >50% + 投资人 1 席/观察员 + 董责险。不可接受：投资人董事席位接近或超过创始人、观察员享表决权。交换条件：接受 1 席董事以换取控盘底线。→ 可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA/新公司法实务（锦天城、法律桥、星河等）。

## 14. 利润分配（优先分红权 / Dividend）

**【条款含义（投资人目的）】** 投资人优先于其他股东分红（或特定情形强制分红）。有限公司无类别股制度下靠协议；股份公司可借新《公司法》第 144–146 条类别股实现。

**【对公司/创始团队的不利点】** 强制/优先分红 → 留存利润被抽走，影响发展与后续估值；有限公司阶段与同股同权张力大且涉税务。

**【公司方谈判要点】** 非必备、可后置（早期尽量不约定；若必须，限"IPO 前累计未分配达 X 触发"）；与反稀释/回购二选一；股份公司阶段借类别股固化。

**【典型可接受的写法建议】** "公司原则上不强制分红；仅在合格 IPO 申报前累计未分配利润超过【X】万元且不影响正常经营时，经股东会决议可按持股比例分配，投资人无优先分红权。"

**【可接受底线】** 可接受：默认不优先分红 + IPO 前不触发。不可接受：强制优先分红长期抽走留存。交换条件：接受类别股框架（股份公司）以换取不签协议优先分红。→ 默认不分红版可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA/新公司法实务（锦天城、法律桥、星河等）。

## 15. 不竞争与创始人限制（Non-Compete & Founder Restriction）

**【条款含义（投资人目的）**】 创始人在职及离职后 1–2 年不得从事竞争业务、不得招揽客户/员工、扩及亲属，确保团队投入。

**【对公司/创始团队的不利点】** 概括式广覆盖 → 限制再创业/投资，与劳动法竞业混淆；扩及亲属 → 家族商业受限；与劳动竞业混同 → 公司可能借"股东不竞争"规避劳动法竞业补偿，反使条款效力存疑。

**【公司方谈判要点】** 列举式限范围（明确行业/地域/产品，拒绝"任何竞争性业务"概括式）；独立于劳动竞业（另签独立竞业协议含补偿）；期限与亲属收窄（离职后 1 年为宜，亲属仅限共同经营/控制）。

**【典型可接受的写法建议】** "创始人于任职期间及离职后 12 个月内，不得自营或为他人经营与本公司【具体产品/服务清单】直接竞争的业务；本条不涉及创始人亲属独立从事之无关行业。公司与创始人应另签独立竞业协议并支付法定竞业补偿。"

**【可接受底线】** 可接受：列举式 + 离职 1 年 + 独立于劳动竞业。不可接受：概括式"任何竞争" + 扩及全部亲属 + 无补偿。交换条件：接受股东不竞争（补充）以换取列举式与期限收窄。→ 限缩版可进「建议放行清单（🟢）」。

**【来源】** 综合公开 SHA 实务（锦天城、恒都等）。

## 16. 股权质押与创始人担保（Share Pledge & Founder Guarantee）

**【条款含义（投资人目的）】** 为担保回购/对赌/陈述保证履行，要求创始人将股权质押给投资人，或要求创始人/关联方个人连带保证、配偶签共债同意函。

**【对公司/创始团队的不利点（⚠️ 个人风险最高）】** 股权质押 + 个人连带保证 → 家庭财产（房产、存款）暴露于回购债务；配偶共债同意函（小马奔腾案 2 亿共债）可能将夫妻共同财产一并执行；质押后创始人再融资/转让受限，质权实现即出局；担保未经《公司法》第 15 条决议程序（为实控人担保须股东会、关联回避）可能无效。

**【公司方谈判要点】** 拒绝个人连带保证（核心：最多以所持股权为限）；质押范围最小化（仅担保"以股权为限的回购义务"所需份额，质权实现先处置股权不追索其他财产）；配偶同意函限缩（仅确认股权共有 + 同意以该股权清偿，不构成个人连带共债）；决议程序合规；日落（随回购权日落自动解除）。

**【典型可接受的写法建议】** "创始人同意就其在公司所持股权（对应其以该股权为限承担的回购义务范围）办理质押登记，质权实现时投资人应先行处置该等股权，不得向创始人其他个人财产追偿。创始人配偶仅出具确认函，确认前述股权之共有状态及同意以该股权清偿，不构成任何个人连带债务。本质押于合格 IPO 申报时自动解除。"

**【可接受底线】** 可接受（已限缩）：以所持股权为限 + 质权先处置股权不追其他财产 + 配偶仅确认函非共债 + IPO 日落。不可接受（🔴红线）：创始人个人无限连带保证 + 配偶个人连带共债 + 无日落。交换条件：接受有限质押以换取删除个人连带保证与配偶共债。→ 此条为「创始人个人责任四项」核心，见卡 17。

**【来源】** 综合公开对赌/SHA 实务与判例（小马奔腾案 (2021)京民终18号；锦天城、兰台、大成等）。

## 17. 创始人个人责任四项（专项卡 · 强制设防）

> 本卡为第 4 步专项扫描的锚点。凡协议出现以下四项之一，一律强制回到卡 1/2/16 设防，并写入交付物「必须清除/限缩」清单（不建议进「建议放行清单」）。

| 项目 | 投资人目的 | 公司方限缩路径（可接受底线） | 风险级 |
|---|---|---|---|
| **① 个人连带** | 创始人个人无限连带责任 | 拒绝；最多"以所持股权为限"；仅"故意/欺诈/刑事"不受限 | 🔴 红线 |
| **② 股权质押** | 质押股权担保履行 | 仅质押为担保"以股权为限义务"所需份额；质权实现先处置股权、不追索其他财产；IPO 日落 | 🟠→限缩后🟢 |
| **③ 个人保证** | 创始人/关联方保证 | 同①；关联回避决议程序（《公司法》第 15 条） | 🔴 红线 |
| **④ 配偶共债** | 配偶签共债同意函 | 仅确认股权共有 + 同意以该股权清偿，不构成个人连带共债 | 🔴 红线 |

**促成交易话术**："我们理解投资人对履约保障的诉求，但创始人个人连带/配偶共债会直接击穿有限责任、影响团队稳定性与后续融资。建议改为以所持股权为限的有限担保，这既给投资人实质保障，又不伤害交易推进。"

**【来源】** 综合公开对赌实务与判例（小马奔腾案；兰台、大成、锦天城；新《公司法》第 15 条）。

## 18. 合格上市条款（Qualified IPO）

**【条款含义（投资人目的）】** 约定公司在特定期限、特定交易所、特定市值完成 IPO，作为回购的免责/终止基准。

**【对公司/创始团队的不利点】** 时间/地点约定过激 → 遇监管关窗（A 股阶段性收紧）必然违约、触发回购。

**【公司方谈判要点】** 时间留弹性（结合基金存续但参考监管风向）；地点多选（北交所/港交所/美股并列）；明确"因监管政策变化致无法上市"不构成违约。

**【典型可接受的写法建议】** "合格上市指公司在【北交所/港交所/纽交所或纳斯达克】之一完成首次公开发行并上市；因境内外证券监管政策重大变化导致公司无法在约定期限内上市的，不视为违约，回购权暂缓行使直至政策恢复。"

**【可接受底线】** 可接受：多地点 + 监管 Carve-out + 弹性时间。不可接受：单一 A 股 + 刚性时间点无豁免。交换条件：接受明确 IPO 里程碑以换取监管豁免。

**【来源】** 综合公开 SHA 实务（锦天城、国创等）。

## 19. 陈述与保证 / 赔偿（R&W / Indemnity）

**【条款含义（投资人目的）】** 公司/创始人就权属、财务、合规、重大合同等作陈述保证；违约则赔偿，且常要求创始人个人连带责任。

**【对公司/创始团队的不利点】** 范围过宽（"对所有重大方面真实准确"无上限）→ 任何历史瑕疵（甚至是投资人尽调应发现的）都可能触发赔偿；赔偿期过长/无上限 → 创始人长期暴露于不确定债务；个人连带赔偿 → 击穿有限责任。

**【公司方谈判要点】** 限定范围（仅"明知且重大"、以披露函（Disclosure Schedule）为免责）；设赔偿上限（如不超过投资本金或持股对应价值）与赔偿期（如交割后 18–24 个月，税务/环保等法定更长）；抗辩机制（投资人未尽调发现的已知事项免责）；拒绝创始人个人连带赔偿（至少以股权为限）。

**【典型可接受的写法建议】** "各方陈述与保证以签署日为准，仅就【明知且重大】的事项负责，已载入披露函的事项免责。任何赔偿请求以投资本金为上限，赔偿期自交割日起 24 个月（税务、环保、知识产权侵权除外，为法定时效）；投资人于尽调中已知或应知的事项不构成本条项下的违约。"

**【可接受底线】** 可接受：披露函免责 + 本金上限 + 24 个月期 + 知情重大。不可接受：无上限无期限 + 创始人个人连带赔偿 + "所有方面"无免责。交换条件：接受合理 R&W 以换取上限与披露函机制。

**【来源】** 综合公开 SPA/交易文件实务。

## 20. 争议解决（诉讼 vs 仲裁）

**【条款含义（投资人目的）】** 通常要求投资方所在地法院或仲裁管辖。

**【对公司/创始团队的比较】** 诉讼：可上诉/再审，但公开审理影响商誉与后续融资；仲裁：快速、保密（不公开、不公示裁决）、专业仲裁员、可自选，涉公司治理/财务审计复杂案件优势明显，但部分仲裁庭强调意思自治、支持回购不（完全）以减资为前提，公司方少一道制衡——需权衡。

**【公司方谈判要点】** 优先争取中立地仲裁（公司所在地或双方认可机构），兼顾保密与专业；避免投资人所在地法院；若接受仲裁须明确机构、规则、地点，且可借"减资前置"作为抗辩（除非条款明确排除）。

**【典型可接受的写法建议】** "因本协议产生的争议，提交【公司所在地/双方认可】仲裁委员会，按其届时有效的规则仲裁；仲裁地为【中立城市】；仲裁语言为中文。仲裁庭应尊重本协议关于回购以完成定向减资为前置的约定。"

**【可接受底线】** 可接受：中立地仲裁 + 保密 + 保留减资前置抗辩。不可接受：投资人所在地法院（公开 + 地利）。交换条件：接受仲裁以换取中立地与保密。

**【来源】** 综合公开回购争议实务与判例（大成、国浩公开文章）。
