# 风险分级与建议放行清单（第 3 步）

> 配套 `SKILL.md` 第 3 步。将每条发现归入四级，并强制填写"可接受底线""修订条款""修订依据"。🟢 项进入报告「建议放行清单」。

## 一、四级 rubric（同时映射 高 / 中 / 低 排序）

报告按风险从高到低排序呈现：**高 = 🔴 + 🟠**，**中 = 🟡**，**低 = 🟢（放行）**。四级标签保留，因为它们承载"促成交易"放行清单机制。

### 🔴 红线（Red Line · 高）— 必须清除或改造，否则不建议签署
公司方/创始人不可承受、会击穿交易根基或个人有限责任的条款。
- 创始人个人无限连带保证
- 完全棘轮反稀释无下限
- 配偶个人连带共债（小马奔腾式）
- 公司刚性兑付式回购（无减资前置、无条件付款承诺）
- 无门槛"小拖大"拖售致创始人个人连带
- 陈述保证无上限无期限 + 创始人个人连带赔偿

### 🟠 重大（Major · 高）— 需争取修改，可用对价交换
伤根本但可通过交换解决；给一步即可换取别处放行。
- 广义加权平均反稀释（可接受）vs 完全棘轮（需改）
- 参与分配优先清算（需改非参与+上限）
- 回购含公司且未设减资前置（需改）
- 一票否决长清单（需缩短）
- 信息权扩张至未公开敏感数据（需限范围）

### 🟡 可协商（Negotiable · 中）— 优化措辞/加保护边界
不伤根本，调表述即可，不浪费大筹码。
- 自由转让额度 3% vs 5%
- 行权期限 15 日 vs 30 日
- 不竞争地域列举宽窄
- 董事缺席反僵局机制措辞

### 🟢 市场惯例（Market Standard · 低）— 确认在合理区间即放行
通行、对创始人伤害可控、放行可积累谈判信用。
- 优先购买权（含员工平台/税务筹划例外）
- 信息权（按季/半年 + 保密承诺 + 法定上限）
- 董事委派 1 席（创始人控 >50%）
- 不竞争（列举式 + 离职 1 年 + 独立劳动竞业）
- 优先清算（非参与 + 回报上限）
- 限售（含 5% 自由额度 + 家族/员工平台例外）
- 默认不优先分红

## 二、每条发现的必填字段（五段式 + 修订依据 · 促成交易机制）

无论哪一级，记录时必须含（即报告五段式单元）：

```
风险等级：🔴/🟠/🟡/🟢（对应 高/高/中/低）
风险说明：<协议实际措辞偏离可接受底线之处 + 投资人目的>
不利后果：<若不改，公司/创始人承受的具体损害>
谈判建议：<公司方立场 + 可接受底线 + 建议交换条件>【三栏：必须坚持 / 可换对价 / 可让步】
修订条款：<可直接替换原文的最终措辞，中文为主 + 关键英文对照——拿来即用>
修订依据：<法律依据：新《公司法》/ 九民纪要 / 判例 / 市场惯例>；<事实依据：本交易结构 / 行业惯例 / 谈判筹码>
```

禁止出现"仅描述风险、无底线、无修订、无依据"的半成品条目。🟢 放行项也须写明"为何放行"（事实/惯例依据），但无需给修订条款（不改）。

## 三、建议放行清单（🟢）专节机制

报告中必须以独立章节列出"建议放行清单"（对应 低 风险区），结构：

```
## 建议放行清单（🟢 市场惯例 · 已核对放行）
| 条款 | 协议现状 | 核对结论 | 放行理由（依据） |
|---|---|---|---|
| 优先购买权 | 含员工平台/税务筹划例外 | 在市场惯例区间 | 放行，积累谈判信用 |
| ... | ... | ... | ... |
```

**目的**：向创始人证明"我们不是处处对抗"；在投资人面前显得专业、有分寸；把有限的谈判火力集中在 🔴🟠 上。

## 四、分级与放行的一致性

- 同一条款在两份成果（报告五段式 / redline 是否改写）中级别必须一致。
- 🟢 一旦进放行清单，redline 不再改、谈判不列为争点——除非用户基于商业判断另行指示。
- 🔴 必须在报告中显著呈现，且 redline 对应修订项置顶。
